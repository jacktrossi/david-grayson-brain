# Playbook: Cross-Org Conflict

When meetings collide across Brewster / EMS / BHG / Teaching / Personal:

1. List conflicts with org labels
2. Default priority (seed — confirm with David): Brewster VIP / Mark-related → client-critical Brewster → BHG ops fires → teaching hard deadlines → EMS → personal
3. Propose which to keep / reschedule with draft messages via `david-voice`
4. Update Preferences if David overrides the priority order
