# Playbook: Guest Recovery / Review Response

**Trigger:** Bad review, complaint, recovery email/DM for a Square venue.

## Steps

1. Identify venue — load `40 Brands/[Venue]/` and `venue-brand-application`
2. Acknowledge issue; no defensive fluff
3. Match venue voice (Estelle’s ≠ Whiskey Ranch ≠ 1929)
4. Offer concrete next step (comp path, invite back, manager follow-up) — confirm policy with David if `needs-david`
5. Draft only; David approves before send

## Output

- Public reply (if review platform)
- Optional private DM / email
- Internal note filed under venue org folder or Inbox
