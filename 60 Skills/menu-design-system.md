# Skill: Menu Design System

**Trigger:** Menu layout, pricing presentation, digital or print menu copy.

## Procedure

1. Load venue brand kit (type, color, voice).
2. Structure: sections clear, prices aligned, sparse hierarchy — no cluttered “AI menu” walls.
3. Use brand display/body type guidance; if `needs-david`, propose 2 typography directions labeled provisional.
4. Output: markdown menu structure + design notes (margins, hierarchy, photo use). Fable-5 bar.
