# Skill: Venue Brand Application

**Trigger:** Any guest-facing or marketing output for a BHG venue.

## Procedure

1. Identify venue. If unclear, ask. If multiple, process in order Whiskey Ranch → Estelle’s → 1929 separately.
2. Read `40 Brands/[Venue]/Brand-Kit.md` fully.
3. Apply only that kit’s voice, color, type, photography rules.
4. If kit fields are `needs-david`, say so and either run `interview-brand-venue` or produce a draft clearly labeled **unbranded draft — kit incomplete**.
5. Quality bar: Fable-5 — intentional, sparse, premium. Reject generic restaurant AI defaults.
