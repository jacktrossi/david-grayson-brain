# Skill: Interview — Gap Fill

**Trigger:** “fill vault gaps”, “what’s still needs-david”

## Procedure

1. Scan vault for `needs-david`, `TBD`, empty brand tokens, empty Toast switcher labels
2. Group gaps by priority: Toast labels → VIP people → brand kits (venue order) → preferences → nice-to-have
3. Run a short targeted interview (one cluster per session)
4. Write updates to the exact paths; clear `needs-david` only when David answered
5. End with remaining gap list
