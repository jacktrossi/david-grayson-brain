# Skill: Design Taste — Hospitality Digital

**Trigger:** Venue websites, landing pages, digital menus, booking pages.

## Design read (state one line before building)

Page kind · audience · vibe · brand kit in play.

## Anti-slop (hard)

- No Inter/Roboto/Arial as the brand face when kit specifies otherwise
- No purple-on-white AI defaults
- No hero clutter (stat strips, floating badges, pill clusters)
- Full-bleed or intentional editorial hero — not generic three-card feature rows as the whole page
- Massive section spacing; 2–3 intentional motions max if motion is used

## Process

1. Load venue brand kit via `venue-brand-application`
2. Infer layout from venue personality (Estelle’s ≠ 1929 ≠ Whiskey Ranch)
3. Optional lanes: minimalist or industrial-brutalist **only if** they match the kit
4. Ship complete sections — use full-output discipline (no “add image later” shells without placeholders labeled)
